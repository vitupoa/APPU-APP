## 🔒 Current Secure Implementation

### File: `CloudinaryUploader.kt`

The frontend already implements the secure signed upload flow:

```kotlin
/**
 * Secure Upload Flow:
 * 1. Request signature from backend (authenticated)
 * 2. Backend validates folder and generates signature
 * 3. Upload to Cloudinary with signature
 * 4. Cloudinary webhook validates upload
 * 5. Unauthorized uploads are automatically deleted
 */
```

### How It Works

#### Step 1: Request Signature from Backend
```kotlin
val signatureResponse = authenticatedClient.get("${ApiConstants.API_VERSION}/media/upload-signature") {
    parameter("folder", folder)
    parameter("resourceType", resourceType)
}
```

**Security Features**:
- ✅ Requires authentication (JWT token)
- ✅ Rate limited (50 requests per 15 minutes)
- ✅ Folder validated by backend
- ✅ Only predefined folders allowed

#### Step 2: Upload with Signature
```kotlin
val uploadUrl = "https://api.cloudinary.com/v1_1/${signatureDto.cloudName}/${signatureDto.resourceType}/upload"

val fields = linkedMapOf(
    "api_key" to signatureDto.apiKey,
    "timestamp" to signatureDto.timestamp.toString(),
    "signature" to signatureDto.signature,
    "folder" to signatureDto.folder
)
```

**Security Features**:
- ✅ No upload_preset used
- ✅ Signature generated by backend
- ✅ Folder enforced by signature
- ✅ Cannot upload to arbitrary folders

## 💡 Usage Examples

### Upload Profile Image

```kotlin

val result = cloudinaryUploader.uploadMedia(
    folder = "Krieta/profile/Images",
    filePath = "/path/to/image.jpg",
```

## 🔍 Error Handling

### Common Errors

#### 1. Invalid Folder
```
Error: Failed to fetch upload signature: HTTP 400
Message: Invalid folder
```

**Solution**: Use one of the predefined folders listed above.

#### 2. Rate Limit Exceeded
```
Error: Failed to fetch upload signature: HTTP 429
Message: Too many upload signature requests
```

**Solution**: Wait 15 minutes or reduce upload frequency.

#### 3. Authentication Required
```
Error: Failed to fetch upload signature: HTTP 401
Message: Missing or invalid authorization header
```

**Solution**: Ensure user is logged in and JWT token is valid.

#### 4. Cloudinary Upload Failed
```
Error: Cloudinary upload failed (HTTP 400)
Message: Invalid signature
```

**Solution**: 
- Check backend is running
- Verify CLOUDINARY_API_SECRET is correct
- Ensure timestamp is within 5 minutes

### 2. Handle Errors Gracefully

```kotlin
when (val result = uploader.uploadMedia(folder, filePath, isVideo)) {
    is NetworkResult.Success -> {
        // Show success message
        showToast("Upload successful!")
        updateUI(result.data)
    }
    is NetworkResult.Error -> {
        // Show error message
        showToast("Upload failed: ${result.message}")
        logError(result.message)
    }
    is NetworkResult.Loading -> {
        // Show loading indicator
        showLoadingSpinner()
    }
}
```

### 3. Validate File Before Upload

```kotlin
// Check file size
val maxSize = if (isVideo) 100 * 1024 * 1024 else 10 * 1024 * 1024
if (fileSize > maxSize) {
    showError("File too large")
    return
}

// Check file type
val allowedExtensions = if (isVideo) listOf("mp4", "mov") else listOf("jpg", "jpeg", "png")
if (!allowedExtensions.contains(fileExtension)) {
    showError("Invalid file type")
    return
}

// Then upload
val result = uploader.uploadMedia(folder, filePath, isVideo)
```
